# Cat Bubble Island — sitio oficial

Sitio estático (ES/EN) con presentación, política de privacidad, eliminación de cuenta, soporte y contacto.
Sin cookies, analítica ni JavaScript.

- Datos del sitio: `site-config.json`.
- Generación y comprobación: `python3 build.py --out _site` (estricto) o `--preview`.
- Publicación: GitHub Actions (`.github/workflows/pages.yml`) en cada push a `main`.

Contacto: catbubbleisland.help@gmail.com
